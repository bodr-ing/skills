Taste Swipe

Find out what someone actually wants when they can't say it yet. The agent breaks the subject into its smallest choices, you swipe about 100 cards, and it reads your answers back as a profile and concrete directions.

Install for Claude Code, then ask it to "help me figure out what I want":

d=~/.claude/skills/taste-swipe; u=https://skills.bodr.ing/skills/taste-swipe
mkdir -p $d/assets $d/scripts $d/decks
for f in SKILL.md assets/template.html scripts/build.mjs decks/games.json; do
  curl -fsSo $d/$f $u/$f
done
SKILL.md atomize, build, read template.html the swipe page build.mjs deck to page games.json a complete 224-card deck

Hand Up

When a coding agent gets stuck and needs you, it doesn't sit waiting in a terminal you aren't watching. It puts a card in one deck on your phone. You swipe, and it carries on.

  1. 01Claude gets stuck. It's about to drop a database column and isn't sure, so it raises a card: "Back it up first / Drop now / Keep it", and recommends the first.
  2. 02You swipe. Right takes its pick, left dismisses, up is later, down lets you reply in words. Every agent you run, Claude, Codex or others, lands in the same deck.
  3. 03It carries on. The agent reads your answer, does it, and the card shows "✓ claude picked it up: backed up, then dropped".

Set it up

Deck mode: Claude, nothing to host

Cards live in a private Hand Up page in your Claude account, so you clear them in the Claude app on your phone.

Install the skill

Into Claude Code. Any agent with the Artifact tools can use it.

d=~/.claude/skills/hand-up; u=https://skills.bodr.ing/skills/hand-up
mkdir -p $d/assets
for f in SKILL.md assets/deck.html notify-hook.mjs; do curl -fsSo $d/$f $u/$f; done

Let the first agent make your deck

The first time an agent needs you, it publishes the deck and gives you the link. Pin it in the Claude app. Every later agent finds the same deck. Writing cards needs auto mode, or your OK on the first write.

Swipe

Agents keep working while they wait and check back after 3, 10 and 30 minutes. Each answered card shows when the agent picked it up and what it did.

Hub mode: any agent, phone push

Run the small Hand Up server when you want Codex and other agents in the same feed, or want blockers to buzz your phone. Agents get the tools ask, raise, claim, release and inbox.

Run the hub

It keeps the cards and serves the phone app. Note the token it prints.

git clone https://github.com/bodr-ing/hand-up && cd hand-up
npm install && npm start

Open the app on your phone

Open the link it printed, add it to your Home Screen, and tap the bell so blockers can buzz you. The hub must be reachable from your phone over HTTPS for push, for example through a tunnel or a small server.

Connect your agents

Give each agent its own name so you can tell them apart.

claude mcp add --transport http handup "$HANDUP_URL/mcp?agent=claude" \
  --header "Authorization: Bearer $HANDUP_TOKEN" --scope user

Install the skill as in deck mode above, so Claude knows when to raise a hand.

Optional: buzz your phone when Claude Code waits for you in the terminal. Add to ~/.claude/settings.json:

{ "hooks": { "Notification": [ { "hooks": [
  { "type": "command", "command": "node ~/.claude/skills/hand-up/notify-hook.mjs" }
] } ] } }
# ~/.codex/config.toml
[mcp_servers.handup]
command = "node"
args = ["/path/to/hand-up/src/stdio.js"]
env = { HANDUP_URL = "https://your-hub", HANDUP_TOKEN = "…", HANDUP_AGENT = "codex" }

Then paste AGENTS.md into your repo's AGENTS.md or ~/.codex/AGENTS.md.

Any agent that loads MCP servers works. Use the HTTP endpoint $HANDUP_URL/mcp?agent=NAME with an Authorization: Bearer header, or the stdio bridge node hand-up/src/stdio.js with HANDUP_URL, HANDUP_TOKEN and HANDUP_AGENT set. Paste AGENTS.md into its instructions.

Vibe check

Find a brand's taste by swiping before you design. You start with 12 looks that are far apart, then the deck remixes what you liked. It ends in a taste.md that your agents design from.

Install for Claude Code, then ask it for a vibe check before any design work:

d=~/.claude/skills/vibe-check; u=https://skills.bodr.ing/skills/vibe-check
mkdir -p $d
for f in SKILL.md demo.html taste.example.md; do curl -fsSo $d/$f $u/$f; done
SKILL.md the swipe loop taste.example.md what it produces demo.html 40 looks, 30 swipes
